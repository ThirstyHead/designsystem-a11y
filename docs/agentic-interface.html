Agentic Interface Protocol

This document defines the standards for AI agents to programmatically consume, implement, and verify the Japandi A11y Design System.

1. Token Consumption

The system's source of truth is tokens.json. Agents should prioritize this file over CSS variables for logic and validation.

Consumption Workflow

  1. Read tokens.json to identify the current version and palette.
  2. Map semantic tokens (e.g., sys.text.main) to their palette values (e.g., #2C2C2C).
  3. Apply these values using the corresponding CSS variables defined in base.css.

2. Implementation Standards

When generating new components or pages, agents must adhere to the following constraints:

  • Semantic HTML: Use landmarks (<main>, <nav>, <footer>) and proper heading hierarchies.
  • Fluidity: Use clamp() for typography and auto-fit for grids to ensure intrinsic responsiveness.
  • Contrast: All text must maintain a minimum contrast ratio of 4.5:1 (WCAG AA). Refer to the contrast_ratio property in tokens.json.

3. Verification Protocol

Before finalizing any output, agents should perform the following checks:

A11y Checklist

  • [ ] Does every image have a descriptive alt attribute or aria-hidden="true"?
  • [ ] Is there a logical focus order for keyboard navigation?
  • [ ] Do all interactive elements have a visible :focus-visible state?
  • [ ] Is the lang attribute set on the <html> tag?
