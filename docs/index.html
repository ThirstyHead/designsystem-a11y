Design System Overview

This is a machine-readable, WCAG-compliant design system based on the Design Tokens Specification (2025.10). It is designed to be consumed by both human developers and agentic AI.

AI-First

The source of truth is tokens.json, allowing LLMs to implement styles without guessing.

Accessibility-First

Every color pair is validated against WCAG 2.1 AA/AAA contrast standards.

Lean Implementation

Zero frameworks. Pure HTML, CSS Variables, and SMACSS architecture.
